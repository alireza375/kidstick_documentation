# Orders

- In this section, the admin will be able to see all the existing orders and their key information.

- Admin can search a specific order by using the **search bar**.

![Order](./img/31.png)


## Here is how to see Order Details !

- To see the details of an order, click on the **View** action button.

- A page will open with the details of the order.

![Order](./img/32.png)

- **You can print invoice by clicking the print invoice button**

![Order](./img/33.png)


![Order](./img/34.png)


## Here is how to delete an order!

- To delete an order, click on the **Delete** action button. A confirmation dialog will appear where you can confirm the deletion of the order.

![Order](./img/35.png)
