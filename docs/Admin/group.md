# Service


- In this section, the admin can create services for users focused on specific sports and physical activities and assign the best coach to them.
- Admin will be able to see all the existing services.
- Admin can search for a specific service by using the **search bar**.


## Here is how to add a new service !
- In this section, the admin can add a new service by clicking the "Add service" button and filling out the required form fields to add a new service.


## Here is how to edit and delete a service !
- In this section, the admin can edit a service by clicking the **Edit** action button and filling in the required form fields. 

- To delete a service, click the **Delete** action button.
