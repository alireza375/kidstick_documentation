# Blog

- In this section, anyone can see the blog section photo and content, here all the sections are dynamic.

- Admin can change it according to his requirement.

- The admin can modify it through the **Blog** page in the admin panel.

- The coach can add the news and updates to the blogs from the coach panel.

- Click on the **Read more** button to see the blog details.

- Anyone can search the blog by using the **search bar**.
